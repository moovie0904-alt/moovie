[대량등록 파일 만들기]

1. 이 폴더(예: C:\자동화시스템\대량등록만들기)에 아래 파일을 넣습니다.
   - make_bulk.py, 대량등록_만들기.bat
   - 양식 파일 1개: 대량등록001.xlsx  (이름이 "대량등록"으로 시작)
   - 원본 파일: 키워드A.xlsx, 키워드B.xlsx  (이름이 "키워드"로 시작, 여러 개 가능)

2. 대량등록_만들기.bat 더블클릭

3. 결과
   결과\키워드A\대량등록0001.xlsx, 0002, 0003 ...
   결과\키워드B\대량등록0001.xlsx, 0002, 0003 ...
   - 원본 A열 상품명 → 양식 A열 / B열 수집URL → 양식 B열 / C열 배송비 → 양식 D열
   - 파일 하나에 49개씩 (2~50행)
   - 양식의 머리글, G열 안내문, 테두리는 그대로 유지
   - 양식 2행에 있던 예시 상품은 지우고 새 상품을 넣음

4. 중간에 멈추면(창 닫기, Ctrl+C, 전원 꺼짐 등) 다시 bat 을 더블클릭
   → 이미 만든 파일은 건너뛰고 이어서 만듭니다.
   → 원본에 상품이 추가되면, 마지막 파일부터 이어서 채웁니다.

※ URL(B열)이 비어 있는 줄은 건너뜁니다.
※ 처음부터 다시 만들려면 결과 폴더를 지우고 실행하세요.


[브랜드 의심 상품명 찾기]  ※ Claude Code 설치 필요 (키워드추천\설치방법.txt 참고)

1. 이 폴더에 brand_check.py, 브랜드검사.bat, 브랜드목록.txt 를 넣습니다.
2. 대량등록_만들기.bat 으로 결과 폴더를 먼저 만든 뒤, 브랜드검사.bat 더블클릭
3. 결과
   - 대량등록 파일에서 브랜드 의심 상품의 A열 칸이 빨간색으로 칠해짐 (상품명 글자는 그대로)
   - 브랜드의심_목록.xlsx : 파일 / 행 / 상품명 / 의심 단어
4. 한 번에 파일 100개(약 4,900개 상품)씩 검사합니다. 다시 실행하면 이어서 검사합니다.
   더 많이 하려면 명령창에서: python brand_check.py --files 300
5. 브랜드목록.txt 에 적은 단어가 들어간 상품명은 Claude에게 묻지 않고 바로 의심으로 표시합니다.
6. 한 번 판정한 상품명은 브랜드검사_판정.csv 에 저장돼 다시 묻지 않습니다.

※ 처음부터 다시 검사하려면 브랜드검사_완료.txt, 브랜드검사_의심.csv 를 지우세요.
※ 실행 중에는 대량등록 파일과 브랜드의심_목록.xlsx 를 닫아 두세요.
